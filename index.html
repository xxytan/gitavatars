GitAvatars

Introduction

A site fully mirrored GitHub User Avatars and hosted on Cloudflare Pages.

Kinder to users from CN Mainland.

Usage

Via UID

  1. Fetch GitHub User ID by executing the command: 
      # Replace `<username>` with your GitHub Username
  curl https://api.github.com/users/<username>

    Then you’ll get the response like:

      {
    "login": "xxytan",
    "id": 155360005,
    "node_id": "U_kgDOCUKbBQ",
    "avatar_url": "https://avatars.githubusercontent.com/u/155360005?v=4",
    "gravatar_id": "",
    "url": "https://api.github.com/users/xxytan",
    "html_url": "https://github.com/xxytan",
    …
  }
  2. Copy the value of “id”, and replace <uid> with it: 
    av.oxue.de/<uid>

    e.g. av.oxue.de/155360005

Via Username (Recommended)

  • Replace <username> with your GitHub username: 
    av.oxue.de/<username>

    e.g. av.oxue.de/xxytan

    It’ll be redirected to its UID automatically

Others
